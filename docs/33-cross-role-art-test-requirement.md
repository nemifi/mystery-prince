# Cross-ROLE Art Requirement for H1 Test

Status: REQUIRED BEFORE EXTERNAL H1 TEST

The current concept shell must not validate PRINCE identity by showing the exact same portrait in both works. That would make recognition trivial and fail to test the star-system proposition.

For each prototype PRINCE, the two works must use visibly different ROLE realizations while retaining the same face/body identity:

| PRINCE | EXPERIENCE A | EXPERIENCE B |
|---|---|---|
| REI | luxury-hotel security director | interwar exhibition curator / diplomatic aide |
| MINATO | private physician | railway investigator |
| KAI | invited illusionist | chief conductor |

## What may change

- costume and uniform
- hair styling within recognizable bounds
- accessories / props
- posture appropriate to ROLE
- lighting and world treatment
- degree of formality

## What should remain recognizable

- facial proportions and key face landmarks
- body/frame impression
- eye/expression signature
- characteristic posture/gesture tendency
- overall appeal core

## Acceptance test

Show the six ROLE portraits without names to a viewer who has seen the first set. The second set should be groupable with the corresponding first-set identities without needing lore explanation, but should not look like the same image with a minor recolor.

The first external H1 user-test wave should not start until this is true.

# ADR-0001 — Separate Prince Identity from Fictional Biography

Status: Accepted

## Context

The IP needs both durable character attachment and high narrative freedom.

A conventional single-continuity character life prevents repeated radical roles, culprit status, death, era changes and other useful mystery situations.

## Decision

Maintain a persistent **PRINCE CORE** while allowing work-specific **ROLE** data to change substantially.

## Consequences

Positive:
- characters remain durable IP assets
- stories retain freedom
- popular characters can appear in many mystery archetypes

Risk:
- if CORE is too weak, roles feel like unrelated characters sharing a face
- if CORE is too strong, story freedom is lost again

# ADR-0003 — Whole-Work-First Mystery Production

Status: Accepted

## Context

Bottom-up composition from reusable game mechanics and generated fragments risks producing logically valid but dramatically weak content.

## Decision

Create the whole work concept / MASTER STORY first. Only then formalize mystery logic and adapt the work into reusable game interactions.

## Consequences

- reusable systems constrain implementation but do not become the source of story ideas
- production tooling must support top-down creative specification
- automated generation should optimize for selected whole-work concepts, not merely component completion

# Temporary Cross-ROLE Art Source

Status: PROTOTYPE ONLY

The concept-test board already contains six distinct ROLE portraits that can be cropped as temporary H1 assets:

- REI — hotel security / museum curator
- MINATO — doctor / detective
- KAI — illusionist / conductor

These crops are acceptable for internal/external concept testing because they introduce meaningful costume/world variation while attempting to preserve PRINCE identity. They are not final launch art and should not become canonical visual assets by inertia.

The purpose of using them is methodological: remove the exact-image-recognition confound before the first H1 test wave.

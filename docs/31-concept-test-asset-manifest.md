# Concept-Test Asset Manifest

Status: WORKING / H1-H2 TEST ONLY

Purpose: define the **minimum visual/audio asset set** required to make the two vertical slices feel intentional enough for user testing without accidentally funding a production game before the format is validated.

## Asset budget principle

Spend where the hypothesis lives:

1. PRINCE identity
2. cross-ROLE transformation
3. expression/reaction payoff
4. key mystery evidence
5. world atmosphere

Do not spend on shops, progression screens, home navigation, elaborate transition systems, or production UI chrome.

---

## PRINCE assets

For each of REI / MINATO / KAI:

### Identity reference

- 1 neutral bust reference
- 1 neutral full-body silhouette reference
- 1 close eye/face reference for consistency

### EXPERIENCE A

- 1 ROLE full-body / 3-quarter portrait
- 5 expression states:
  - neutral
  - slight warmth/amusement
  - focused/serious
  - destabilized/surprised
  - post-accusation-specific
- 2 signature gesture poses

### EXPERIENCE B

- 1 radically different ROLE full-body / 3-quarter portrait
- same 5 expression categories, adjusted to ROLE context
- same 2 signature gestures recognizable across costume changes

### Total target per PRINCE

Approximately 15–18 usable visual states, but produced from a smaller consistent source sheet where possible.

The test should not rely on animation.

---

## EXPERIENCE A — THE 23:30 MESSAGE

### Backgrounds

Minimum:

1. luxury hotel restricted corridor / city-night view
2. victim room / controlled investigation view
3. hotel lounge or interview area
4. abstract hotel system / message-management visual

Backgrounds may be reused with lighting/crop changes.

### Evidence visuals

1. 23:30 voice-message notification / delivery record
2. preliminary death-time information card
3. altered security-log excerpt
4. unauthorized access credential / access record for KAI
5. scheduled-message system proof
6. room-state / claimed-contact contradiction visual
7. physician emergency-kit / fatal-agent access evidence

Only evidence required for fair reasoning needs bespoke art.

### Hero visual

One episode key visual containing all three ROLE designs, with MINATO positioned as the most emotionally approachable figure rather than visually coded as villain.

---

## EXPERIENCE B — THE SEALED EXPRESS

### Backgrounds

Minimum:

1. luxury night-train corridor / compartment
2. exhibition/dining carriage with sealed display
3. snow / tunnel exterior establishing image
4. pre-departure platform or photography area

### Evidence visuals

1. intact seals / display close-up
2. replica jewel close-up
3. KAI procedure-violation record
4. pre-departure official photograph showing replica feature
5. comparison detail: authenticated original vs replica
6. REI custody/access record before sealing
7. non-public inclusion/detail reference for the original

### Hero visual

One episode key visual containing the same three PRINCES in dramatically different ROLE clothing. Recognition should occur before the labels are read.

# PRINCE CORE — Minimum Internal Contract

Status: WORKING

## Brand principle

Do not narrowly define what a PRINCE is for users. PRINCE is a broad brand label for attractive male characters presented by MYSTERY PRINCE.

The internal production system nevertheless needs a small invariant contract so that a recurring PRINCE remains recognizable across radically different ROLEs and worlds.

## Minimum core

### Appeal Core
Why the audience wants to keep watching this character.

### Decision Principle
What the character tends to prioritize when values conflict or uncertainty is high.

### Interpersonal Style
How the character approaches, trusts, tests, controls, protects, avoids, or relates to other people.

### Emotional Pattern
What tends to move the character emotionally and how that emotion is expressed or concealed.

### Signature
A small set of recognizable expressive traits such as speech rhythm, humor, mannerism, presence, visual motif, or characteristic behavioral cue.

## Explicitly outside PRINCE CORE by default

Occupation, era, fixed family structure, fixed past events, permanent romance, permanent moral role, investigator/suspect/culprit status, and experience-specific relationships belong to CASTING/ROLE/EXPERIENCE unless deliberately promoted later.

## Design principle

PRINCE CORE is not a biography. It is a portable character dynamic.

The validation question is not “Are all facts identical across works?” It is “When placed into a different life, does this still feel like the same star?”

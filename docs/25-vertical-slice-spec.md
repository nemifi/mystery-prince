# H1/H2 Vertical Slice Creative Specification

Status: WORKING

## Objective

Create two short, polished experiences that can test the product idea without pretending to be the final commercial Runtime.

The slices must demonstrate:

- durable PRINCE identity across radically different ROLEs
- genuine mystery reasoning
- emotional conflict between character attachment and suspicion

Approximate target: 10–15 minutes per slice.

## Shared presentation rules

### Preserve PRINCE identity
Across A and B, each PRINCE should retain enough stable representation that identity is immediate:

- face / core silhouette identity
- voice identity if voiced
- speech rhythm
- signature mannerism or behavioral beat
- the five PRINCE CORE dynamics

### Change ROLE strongly
Do not protect H1 by making the two versions nearly identical.

Change:

- costume
- social authority
- profession
- era
- relationship to the investigation
- moral/narrative function

The user should feel recasting, not sequel continuity.

### No continuity explanation
Do not add lore explaining why the same characters appear in both worlds.

The brand/presentation may clearly frame them as recurring PRINCES, but the fictional stories remain independent.

### Mystery must require thought
Each slice needs at least one moment where the user must actively update a hypothesis from evidence. Merely choosing the next dialogue option is insufficient.

## Slice A — THE 23:30 MESSAGE

### 0–2 min: attraction and impossible hook

Introduce the hotel-floor lockdown and the three men rapidly.

Character targets:

- ALPHA takes control without asking permission.
- BETA notices the player's discomfort or uncertainty and creates immediate interpersonal safety.
- GAMMA treats the impossible message with inappropriate amusement.

End the opening with the victim's 23:30 voice message after the player has already been told he should be dead.

### 2–5 min: establish trust and suspicion

Let BETA function as the easiest person to emotionally trust.

Let ALPHA control evidence/access strongly enough that the user has a reason to resent or suspect him.

Give GAMMA one memorable boundary-testing interaction.

### 5–8 min: first solution

Reveal ALPHA's manipulated security record.

The slice should make “ALPHA did it” feel emotionally and logically plausible for a short period.

The user must make at least one explicit reasoning choice supporting or rejecting that theory.

### 8–11 min: collapse the first solution

Reveal that ALPHA's lie protects a separate secret and cannot explain the message timing.

Expose the scheduled-message possibility.

The important reasoning update is:

> delivery time ≠ recording time

### 11–14 min: affection becomes friction

BETA says or knows something about the room state that he should not know under his claimed timeline.

The player must choose whether to challenge the character positioned as the emotional safe point.

The desired reaction is not just “BETA is suspicious.” It is:

> “I don't want BETA to be the answer, but I have to check.”

### End beat

For a 10–15 minute concept slice, the test may end immediately after the successful challenge or include the accusation depending on pacing.

The player must understand the direction of the true solution even if the full 30-minute production version would contain more intermediate reasoning.

## Slice B — THE SEALED EXPRESS

### 0–2 min: immediate recasting shock

Reintroduce the same three faces with no continuity exposition:

- ALPHA is now the refined curator responsible for the jewel.
- BETA is now the railway investigator.
- GAMMA is now the chief conductor.

The first design test is whether users naturally accept “this time he is...” language.

Then trigger the tunnel blackout and replica-jewel reveal.

### 2–5 min: use changed ROLE against expectations

GAMMA now represents institutional authority but still tests rules and people in a GAMMA-specific way.

BETA now occupies the trustworthy investigative function that was dangerous in A.

ALPHA's precise control appears protective rather than police-like.

### 5–8 min: first solution

Expose GAMMA's real procedural violation.

The user should be able to build a plausible “GAMMA used the blackout” theory.

### 8–11 min: shift the time question

Introduce the pre-departure image.

The reasoning update is:

> the interesting question is not “how was the sealed case opened?” but “when was the real jewel last definitely present?”

BETA should help frame the human testimony but must not solve the logical step for the user.

### 11–14 min: identity inversion

Evidence places meaningful pre-departure access with ALPHA.

His extreme precision—an attractive PRINCE CORE trait—now becomes suspicious.

The slice should end with the player forced to consider ALPHA as culprit, creating a mirror of A where a different PRINCE CORE is weaponized by the mystery.

## Cross-slice H1 design test

The same signature trait should produce different narrative meaning:

- ALPHA's control: protective authority in A → meticulous culprit behavior in B
- BETA's human-first instinct: destructive loyalty in A → investigative strength in B
- GAMMA's boundary testing: suspicious outsider behavior in A → suspicious official behavior in B

If the traits only work in one ROLE family, the PRINCE CORE is not portable enough.

## Minimum asset package for a credible test

For each PRINCE:

- one stable base visual identity
- one Work-A costume
- one Work-B costume
- at least 3 useful expression states
- one repeatable signature behavior/pose

Per work:

- 2–4 strong backgrounds or presentation environments
- a small number of evidence visuals central to the reasoning
- coherent sound/BGM direction
- enough transition/presentation polish to avoid “prototype roughness” dominating feedback

Voice is valuable for identity continuity but not mandatory for the first test if it materially slows iteration.

## What not to add

Do not add:

- affection meters
- character collection
- persistent relationship state
- monetization prompts
- lore linking A and B
- runtime LLM dialogue
- a large generic investigation feature set

Every minute of the slices should contribute either to H1, H2, or mystery comprehension.

## Exit condition

The slices are ready when an external tester can judge the concept on its intended merits, not when every future game system has been prototyped.
